# MoviePilot 思齐站点插件集（V3）

本仓库收录适配 **MoviePilot V3** 的思齐站点（`si-qi.xyz`）小游戏自动化插件，作者 `tycgd`。

> 仅用于自动化**你自己的账号**，请遵守站点规则；插件不包含登录/验证码破解，不提供任何共享 Cookie。使用自动化存在被站点判定异常的风险，请自行评估。

## 插件列表

## 安装

1. MoviePilot 版本要求 **>= 3.0.0**。
2. 进入 MoviePilot：**插件 → 插件市场 → 添加仓库 / 自定义源**，填写本仓库地址：
   ```
   https://github.com/tycgd/MoviePilot-Plugins
   ```
3. 刷新插件市场，找到对应插件安装即可。
4. 安装后在「配置」页填写/确认站点 Cookie 并**启用插件**。

## 通用前提：站点 Cookie

- 三个插件都通过 MoviePilot 的「站点管理」读取 `si-qi.xyz` 的 Cookie（`SiteOper`）。
- 若站点管理里没有 `si-qi.xyz`，可在插件配置页的 `Cookie` 项直接填写；留空则回退站点管理。
- Cookie 过期会报 `auth_failed`，重新登录站点更新 Cookie 即可。
- 配置页的 Cookie 以密码框显示，不会明文展示；请勿把配置页截图外发。

## 一、思齐炼魔丸（SiQiCleanBeachV3）

**功能**：自动搬砖（每日上限 50 块）、清理沙滩拾取物品、按库存递归炼造魔丸。

- 触发：定时（默认间隔约 2 小时）/ 配置页「立即运行」/ 详情页按钮。
- 远程命令：`/siqi_clean_beach`
- 主要配置：搬砖开关与单次上限、炼造开关与目标数量、通知开关、调度方式（interval/cron）。
- 详情页：Hero 概览、砖块进度、库存、炼造配方结果与历史。

## 二、思齐钓鱼（SiQiFishingV3）

**功能**：自动抛竿收竿（完美/甜蜜区/自定义滑块）、鱼饵/鱼竿策略、补饵预算、任务交付、每日竞猜。

- 调度：默认每 61 分钟检查一次；按 6 个时段（每 4 小时）分配每日 33 次抛竿。
- 时段配额：`slot_strategy=auto` 自动把剩余次数平均分到剩余时段；耗尽后**静默跳过**，不再产生空跑日志/通知。
- 任务与鱼竿：鱼竿由任务一~五解锁；插件自动交付 ready 任务，并**保护收集任务必需鱼**——可重复小任务（如任务七/八）若会吃掉未完成收集任务所需的鱼，会跳过交付，避免任务永远凑不齐。
- 任务缺口：详情页/通知会显示「缺哪种鱼、对应时段」。
- 远程命令：`/siqi_fishing`
- 详情页快捷操作：钓 1 竿 / 同步状态 / 交付任务 / 切换鱼饵鱼竿与收竿方式。
- 建议：推进任务三（稀有）之后开启 `auto_buy` 并设置每日购饵预算，否则仅靠免费蚯蚓饵概率偏低。

## 三、思齐开餐馆（SiQiRestaurantV3）

**功能**：自动开店、按顾客需求采购食材并上菜、过期顾客处理、员工雇佣、每日下馆子。

- 调度（默认）：**每天 10:12 营业**；**每天 15:12 补查一次**（当天已完成则静默跳过）。可在配置页修改 `cron` 与 `retry_cron`。
- 上菜节奏：每单耗时 = `max(最小间隔, 菜品烹饪时间 ÷ 已解锁灶台数) + 拖拽食材 1.5~3s + 上菜 2~4s`，接近真人操作。
- 数据日期：页面会校验数据是否为今天；若为历史快照，会显示「今日尚未经营 / 待同步」提示，点「仅同步状态」刷新即可。
- 远程命令：`/siqi_restaurant`
- 主要配置：演练模式、自动开店、自动采购与预算、上菜策略（按顾客指定/优先便宜/优先贵价）、自动雇佣、自动下馆子、单次上菜上限、调度 cron。
- 快捷操作：立即运行一轮（后台）、立即上菜（后台一次性任务，最多 3 位）、仅同步状态、切换演练模式。

## 常见问题

| 现象 | 排查 |
| --- | --- |
| 定时任务不跑 | 配置页确认**启用插件**；未启用时只有手动/命令能触发。 |
| 提示 Cookie 失效 | 重新登录 `si-qi.xyz`，更新站点管理或插件配置里的 Cookie。 |
| 详情页显示旧数据 | 点「仅同步状态」；页面会提示数据日期与今天不一致。 |
| 钓鱼任务不交付 | 收集任务需集齐指定鱼种；看详情页「任务缺口」，并按提示时段去钓。 |
| 鱼竿不解锁 | 鱼竿由任务一~五解锁，先把对应收集任务完成并交付。 |
| 餐馆显示「今日尚未经营」 | 今天还没同步或还没开店；启用插件后会按 10:12 / 15:12 自动处理，或手动「立即运行一轮」。 |
