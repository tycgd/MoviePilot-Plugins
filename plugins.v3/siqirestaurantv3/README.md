# 思齐开餐馆（SiQiRestaurantV3）

MoviePilot V3 插件：思齐站点「开餐馆」小游戏自动化。

## 功能
- 自动开店：每天 10:12 自动营业；每天 15:12 补查一次（当天已完成则静默跳过）。
- 自动采购与上菜：按顾客指定菜品采购食材并上菜；支持按顾客指定 / 优先便宜 / 优先贵价策略。
- 拟真节奏：每单 = 菜品烹饪时间 ÷ 已解锁灶台数 + 拖拽食材 1.5~3s + 上菜 2~4s。
- 其他：过期顾客处理、自动雇佣员工、每日下馆子（默认关闭）、完成通知。
- 数据新鲜度：页面会区分「今日实时」与「上次运行快照」；历史数据会提示并显示「今日尚未经营 / 待同步」。

## 使用
1. 安装并启用插件，确认 `si-qi.xyz` Cookie。
2. 首次建议开启「演练模式」跑一次，只同步不写操作。
3. 关闭演练模式后，可等每天 10:12 自动运行，或点「立即运行一轮」。
4. 快捷操作：立即运行一轮（后台）、立即上菜（后台，最多 3 位）、仅同步状态、切换演练模式。
5. 远程命令：`/siqi_restaurant`

## 主要配置
| 配置 | 默认 | 说明 |
| --- | --- | --- |
| schedule_mode / cron | cron / `12 10 * * *` | 每天 10:12 营业 |
| retry_enabled / retry_cron | true / `12 15 * * *` | 每天 15:12 补查 |
| dry_run | false | 演练模式（只读） |
| auto_start_session | true | 有顾客时自动开店 |
| auto_purchase / buy_budget_per_day | true / 5000 | 自动采购与每日预算 |
| serve_strategy | match | 按顾客指定 / cheapest / expensive |
| min_serve_delay_seconds | 2 | 上菜间隔下限（实际按烹饪时间计算） |
| max_customers_per_run | 0 | 单次最多上菜数，0=不限 |
| auto_hire_staff | true | 人气≥10000 解锁后自动雇佣 |
| auto_visit / visit_count_limit | false / 3 | 自动下馆子与每日上限 |

## 说明
- 请保持插件「启用」，否则定时任务不会运行。
- 页面若提示「数据日期 ≠ 今天」，点「仅同步状态」刷新。
- 旧版 `interval/30 分钟` 默认配置会在升级后自动迁移为 `10:12 营业 + 15:12 补查`。
