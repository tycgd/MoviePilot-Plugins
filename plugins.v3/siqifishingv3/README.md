# 思齐钓鱼（SiQiFishingV3）

MoviePilot V3 插件：思齐站点钓鱼自动化。

## 功能
- 自动抛竿/收竿：完美、甜蜜区、自定义滑块三种收竿方式。
- 鱼饵/鱼竿策略：自动选择库存权重最高或固定指定；可选自动购饵与预算。
- 时段分配：每日默认 33 次，按 6 个 4 小时时段自动分配；时段配额用完后静默跳过（不空跑、不发通知）。
- 任务交付：自动交付已达成任务；**保护收集任务必需鱼**，不会让可重复小任务吃掉任务一~五所需的鱼。
- 任务缺口提示：详情页/通知显示缺哪种鱼、对应时段。
- 每日竞猜。

## 使用
1. 安装并启用插件，确认 Cookie。
2. 建议保持 `slot_strategy=auto`，覆盖所有时段（不同鱼只在特定时段出现）。
3. 推进稀有以上任务时，开启 `auto_buy` 并设置每日购饵预算。
4. 远程命令：`/siqi_fishing`；详情页可「钓 1 竿 / 同步状态 / 交付任务 / 切换鱼饵鱼竿」。

## 鱼竿解锁条件
| 鱼竿 | 解锁 |
| --- | --- |
| 蘑菇竿 | 默认 |
| 绿叶竿 | 任务一（普通鱼集合） |
| 浮漂竿 | 任务二（不常见鱼集合） |
| 鱼仔竿 | 任务三（稀有鱼集合） |
| 爱心竿 | 任务四（史诗鱼集合） |
| 星星竿 | 任务五（传说鱼集合） |

## 主要配置
`lure_mode/lure_key`、`rod_mode/rod_key`、`slider_mode`、`max_casts_per_run`、`daily_cast_limit`、`cast_interval`、`auto_buy/buy_budget_per_day`、`auto_task`、`auto_guess`、`slot_strategy/per_slot_casts`、`dry_run`。

## 说明
- 站点 Cookie 过期会提示认证失败。
- 知识问答（额外次数）页面未暴露接口，暂不支持自动作答。
